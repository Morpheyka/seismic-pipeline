# 3. Методы

## Суточные REM-профили

По гипнограмме строят суточный профиль парадоксального сна: доли времени в ПС в последовательных временных бинах. Профиль задают числом точек на сутки \(N\) и долей перекрытия соседних окон \(\mathrm{ov}\). Классическая схема из двенадцати неперекрывающихся двухчасовых бинов соответствует \((N,\mathrm{ov})=(12,0)\). В основном прогоне используют сетку \(N\in\{12,24\}\) (без \(N=48\)), \(\mathrm{ov}\in\{0,0{,}25,0{,}5\}\); стадия ПС в гипнограмме — метка `rem_stage=2`.

## Признаки и маскирование суток

По профилю суток \(P=(p_1,\ldots,p_N)\) вычисляют среднее \(\bar P=N^{-1}\sum_i p_i\) и размах \(R=\max_i p_i-\min_i p_i\). В переборе используют суточные и полусуточные (светлая/тёмная половина) значения этих величин; комбинации ограничены тремя блоками. Каждый восьмидневный ряд масштабируют в \([-1,1]\) **только по валидным суткам** окна.

Сутки с артефактами записи и сутки без гипнограммы объединяют в единую маску: признаки на этих сутках ставят в NaN и **пропускают** в правдоподобии (без импутации и без укорочения сетки \(\tau\)). Каноническая карта артефактов (0-based): R2 2022-11-07 before \(\{0\}\); R2 2023-05-03 before \(\{2,3\}\); R3 2023-05-03 before \(\{2\}\); R2 2023-04-21 after_reversed \(\{1,2\}\). Окно входит в выборку при числе валидных суток \(\ge K=6\). Для Beta-семейств размах дополнительно сжимают с носителя \([0,2]\) на \((0,1)\) (`support_upper=2`).

## Модель одной точки разладки

Для вектора признаков \(\mathbf{x}_t\) на сутках \(t=1,\ldots,8\) принимают модель с одним переключением режима:

\[
\mathbf{x}_t \sim
\begin{cases}
p(\mathbf{x}_t\mid\boldsymbol{\theta}_1), & t < \tau,\\
p(\mathbf{x}_t\mid\boldsymbol{\theta}_2), & t \ge \tau.
\end{cases}
\]

Параметр \(\tau\) — дискретное положение разладки; априори он равномерен на \(\mathcal{T}=\{2,\ldots,8\}\). Дискретное \(\tau\) маргинализуют для NUTS [HoffmanGelman2014]:

\[
p(\mathbf{y}\mid\boldsymbol{\theta})
=
\frac{1}{|\mathcal{T}|}
\sum_{k\in\mathcal{T}}
p(\mathbf{y}\mid\tau{=}k,\boldsymbol{\theta}).
\]

Апостериор \(p(\tau{=}k\mid\mathbf{y})\) и \(\mathbb{E}[\tau\mid\mathbf{y}]\) восстанавливают по сэмплам \(\boldsymbol{\theta}\). Общий \(\tau\) разделяют между активными признаками одной конфигурации. Plate-схема модели (`images/tau_model.tikz`, как в препринте «Определение стресса…» / отчёт 072026): \(\tau\sim\mathrm{DiscreteUniform}(\mathcal{T})\), индикатор \(z_t=\mathbb{1}[t<\tau]\), наблюдения \(x_{e,t,f}\), правдоподобие Student-\(t\) по признакам \(f\in\mathcal{F}\) и пунктирная маргинализация \(\tau\) перед NUTS.

## Семейства правдоподобия и критерии отбора

Для **среднего** в сетке: Student-\(t\) и skew-normal. Для **размаха** в exploratory-сетке сравнивают четыре кандидата на \((0,1)\): plain Beta; `beta_constrained` (\(\alpha,\beta\ge 1\), без U-формы); zero-inflated Beta (ZOIB, масса у нуля); interval-inflated Beta (IIB@\(0{,}9\), масса на \([0{,}9;1]\)).

Содержательные утверждения о \(\tau\) делают только по семействам размаха, прошедшим **скрининг**: (i) апостериор \(\mathbb{E}[\tau]\) не концентрируется на нижней границе prior \(\tau=2\); (ii) нет диагностического завышения elpd за счёт граничной плотности (как у plain Beta). Семейства, не прошедшие скрининг, остаются в Methods/Results как контроль спецификации, но **не** входят в основной анализ \(\tau\). По итогам скрининга (раздел «Результаты») основной анализ по размаху ведут на **IIB**.

## Сравнение моделей и вывод

Качество обобщения оценивают PSIS-LOO [Vehtari2017]: единица наблюдения — пара «событие–крыса»; для разного числа признаков используют \(\overline{\mathrm{elpd}}/(F\cdot E')\). Сравнивают elpd только внутри одного observation builder (mask ON, \(K=6\)). Влиятельные окна по Парето-\(\hat k\) **не удаляют**; отчитывают ID. Сэмплирование — NUTS (в т.ч. BlackJAX) при маргинализации \(\tau\); контролируют \(\hat R\), ESS и Парето-\(\hat k\).
