# 7. Выводы

1. Построена байесовская модель одной точки разладки для восьмидневных рядов признаков ПС с маргинализацией \(\tau\in\{2,\ldots,8\}\), NUTS и сравнением конфигураций по нормированному PSIS-LOO elpd при day-mask (\(K=6\), \(n=34\)).

2. **Разведены роли elpd и \(\tau\):** медианы elpd/\(F E'\) между range-семьями близки; глобальные LOO-лидеры — преимущественно ZOIB/plain Beta с \(\mathbb{E}[\tau]\) у prior. Содержательные утверждения о разладке опирают на **IIB** и диагностику \(\tau\); elpd — для ранжирования конфигураций внутри одного builder.

3. Семейства размаха прошли скрининг по диагностике \(\tau\): plain Beta, `beta_constrained` и ZOIB дают массу \(\mathbb{E}[\tau]\) у нижней границы prior; **IIB@0.9** — нет (\(0\%\) при \(n=366\)). Остальные семьи — контроль спецификации.

4. На IIB: \(\mathbb{E}[\tau]\approx 5{,}5\) (медиана \(\approx 5{,}6\)); mean+range медиана \(\approx 5{,}7\); mean-only без range \(\approx 5{,}8\) без пика у \(\tau=2\).

5. Байесовский \(\tau\) и классическое окно эффекта размаха (\(2\)–\(4\) сут) — разные estimand'ы. Негативный контроль на трёх семенах не даёт резкого null-контраста. Результат — REM-ассоциированная смена режима при явной маске, без EQ-прогноза и без silent drop влиятельных окон.
