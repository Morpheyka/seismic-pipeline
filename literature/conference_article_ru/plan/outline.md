# Подробный outline

## 1. Введение

- Нейросейсмология и инструментальные физиологические ряды
- REM / стресс у грызунов (осторожная интерпретация)
- Классика: размах профиля ПС, окно эффекта 2–4 сут
- Наш estimand: onset \(\tau\) на 8 сутках; **инверсия индекса \(\tau\)**
- Вклад: байесовская разладка + полный перебор + оговорки LOO/границы Beta
- Не заканчивать длинным «картой глав»

## 2. Данные

- Станция, животные, регистрация, этика
- Гипнограмма (эпохи 5 с, критерии ПС)
- События, интенсивность, окна before / after_reversed
- Объём выборки экспорта (~33 полных профиля)
- Токсичные/неполные профили — факт данных, детали в обсуждении

## 3. Методы

- REM-профили: \(N\times\mathrm{overlap}\) (классика \(12\times 2\)ч ≡ \((12,0)\))
- Признаки: mean, range (размах профиля ПС), daily / day-night
- Модель одной разладки, маргинализация \(\tau\), prior на \(\tau\)
- Likelihoods: student_t/normal; beta / constrained / IIB ([ДОРАБОТКА])
- PSIS-LOO, нормировка elpd
- MCMC / сходимость (кратко)

## 4. Эксперимент (полный перебор) — ЦЕНТР

- Дизайн сетки \(N\times\mathrm{overlap}\), daily-агрегаты
- Критерии eligible / Pareto
- Сравнение elpd только внутри одного builder
- Бюджеты MCMC

## 5. Результаты

- Устойчивость \(\mathbb{E}[\tau]\) / квартили (с календарной интерпретацией)
- Ранги признаков: concat:mean vs daily:range — зависимость от сетки
- Таблицы/рисунки из существующих артефактов (не mock как «доказательство»)
- Boundary Beta — кратко как результат аудита, детали/primary — в обсуждении

## 6. Обсуждение

- 2–4 сут (эффект) vs onset \(\tau\) (с учётом инверсии индекса)
- Почему не удаляем влиятельные события из заголовка; with/without
- **Primary A/B** как рамка чистоты после перебора
- Ограничения: малая выборка, одна разладка, after_reversed, neg-control

## 7. Выводы

- Нумерованные пункты, согласованные с Results/Discussion
- Без завышенных заявлений о стрессе/прогнозе
