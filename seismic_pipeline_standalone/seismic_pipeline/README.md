# `seismic_pipeline` (standalone)

This package provides a **scikit-learn-style pipeline** for seismic-event experiments where many preprocessing steps must **transform targets (`y`) together with features (`X`)**.

It is designed to support workflows like:

- Expand each event into one or more **time windows** (positive/control) → produce labels
- For each window: load/cache hypnogram data (local + optional S3 fallback)
- Compute **REM profiles** and extract features
- Train / cross-validate a classifier and run **hyperparameter search**
- Generate reports and visualizations of grid-search results

## Key idea: target-aware transformers (the `Yt` convention)

Most components in this package are suffixed with **`Yt`** and follow a target-aware convention:

- Transformers implement `transform(X, y)` and return **`(X_transformed, y_transformed)`**.
- `PipelineYt` propagates `(X, y)` through all steps.
- `PipelineYt.predict(X)` returns **`(y_pred, y_true_transformed)`** so scorers can use the transformed labels that match the transformed samples.

This is essential because some transformers (e.g. `EventLabelGeneratorYt`) **expand** the dataset and therefore must expand `y` accordingly.

## Package layout

- **`seismic_pipeline.mod`**: target-aware pipeline primitives (`PipelineYt`, `GridSearchCVYt`, scoring helpers).
- **`seismic_pipeline.seismo`**: seismic domain transformers (events → REM profiles → features, cache manager).
- **`seismic_pipeline.visualization`**: visualization/report helpers (grid-search slices, report generator).

## Quickstart (minimal)

```python
from sklearn.linear_model import LogisticRegression

from seismic_pipeline import (
    PipelineYt,
    EventLabelGeneratorYt,
    REMProfileCalculatorYt,
    REMProfileCleanerYt,
    REMProfileMaxMinExtractorYt,
    HypnogramCacheManagerYt,
)

events = [
    {"rat_id": "R2", "date": "2022-11-07"},
    {"rat_id": "R3", "date": "2022-12-01"},
]

cache = HypnogramCacheManagerYt(local_cache_dir="./hypnogram_cache")

pipe = PipelineYt([
    ("label_generator", EventLabelGeneratorYt(window_days=3)),
    ("rem_calc", REMProfileCalculatorYt(cache_manager=cache, fail_on_missing_data=False)),
    ("clean", REMProfileCleanerYt()),
    ("extract", REMProfileMaxMinExtractorYt(include_other_stats=True)),
    ("classifier", LogisticRegression(max_iter=200)),
])

pipe.fit(events)                 # y is generated by the label generator
y_pred, y_true = pipe.predict(events)
```
